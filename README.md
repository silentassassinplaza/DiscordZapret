> WinDivert может применяться разными программами, включая вредоносные, но сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит компоненты WinDivert к инструментам повышенного риска или хакерским утилитам. В результате файл удаляется и переносится в карантин. В таком обнаружении обычно присутствует имя `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить каталог в исключения; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала включите Secure DNS (безопасный DNS).
   * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/) особенно пригодится пользователям Windows 11.
   * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/silentassassinplaza/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно пропустить.

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
   * Чтобы определить рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для установки стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> выберите подходящую стратегию.

## ℹ️ Что делают файлы

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте варианты ALT, FAKE и другие, пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода, автозапущенной стратегии и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  После изменения параметра стратегию необходимо перезапустить.  
  В скобках отображается текущий статус: включено или выключено.
  - **`IPSet Filter`** задаёт режим обхода сервисов из `ipset-all.txt`.  
  Это полезно при диагностике ресурса, который без zapret работает, а с ним — нет.  
  Доступные состояния:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — IP проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет выбранный используемый фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины, из-за которых zapret может не запускаться или не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` тестирует DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если этого не произошло, воспользуйтесь обсуждением [#522](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/522).

### Не удаётся подобрать стратегию

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не подключается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - скопируйте весь текст из открывшегося блокнота;
  - в появившемся каталоге откройте файл `hosts` текстовым редактором, запущенным от имени администратора;
  - вставьте скопированный текст в конец файла `hosts` или замените ранее добавленные аналогичные строки;
  - сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/silentassassinplaza/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или прекратил работать

> [!IMPORTANT]
> **Стратегии могут становиться нерабочими со временем.**
> Обнаружение определённой стратегии может произойти спустя некоторое время, даже если сначала она работала.
> В репозитории есть разные варианты обхода. Если готовые стратегии не подходят, создайте новую на основе одной из них и измените параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок.
- Удостоверьтесь, что адрес ресурса присутствует в списках доменов или IP.
- Проверьте другие стратегии, включая **`ALT`** и **`FAKE`**.
- При необходимости выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и другие нужные данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Затем выберите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте `Y`.
- Удалите старый каталог zapret.
- Загрузите последнюю версию [`zapret-discord-youtube-...`](https://github.com/silentassassinplaza/zapret-discord-youtube/releases).
- Откройте свойства архива через контекстное меню. Если внизу справа есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- По очереди запускайте разные скрипты `general` и проверяйте нужные интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 запрашивает цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows, открыв `cmd` через Win+R:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше сервис работал.
- См. также [#251](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8F-использование) включён.
- Сначала выясните, с какой стратегией открывается YouTube, и запустите её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте, помогла ли очистка в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей.
- Если веб-версия также недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/silentassassinplaza/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не решит проблему, дополнительно включите `ipset any`.

Учтите, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если это тоже не помогло, создайте тему в разделе [Discussions](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Создайте обращение [здесь](https://github.com/silentassassinplaza/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Списки обхода можно дополнить собственными адресами:
- **`list-general-user.txt`** предназначен для доменов; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** исключает домены, например когда сеть уже находится в `ipset-all.txt`, но конкретный домен фильтровать не нужно.
- **`ipset-all.txt`** содержит IP-адреса и подсети.
- **`ipset-exclude-user.txt`** используется для исключения IP-адресов и подсетей.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
